## Acceso al panel

1. Ir a `/login` en el dominio de la tienda.
2. Iniciar sesión con cuenta de **administrador** o **empleado** (según permisos).
3. El panel vive bajo rutas como `/dashboard`, `/mercados`, `/pedidos`, etc.

Solo usuarios con rol `admin` o `employee` pueden acceder al panel. Algunas secciones (usuarios, legal, mensajes de contacto) son exclusivas de `admin`.
