# My Korea Store (MKS)

E-commerce con **Next.js 16**, **Supabase** y **Mercado Pago** (mercados multidivisa).

## Documentación

Toda la guía del proyecto (spec, arquitectura, base de datos, **agents.md**, **claude.md** y arranque local) está en **[`docs/README.md`](./docs/README.md)**.

- **Manual de uso del panel:** [`docs/manual-usuario/manual-administracion.md`](./docs/manual-usuario/manual-administracion.md)
- **Especificaciones de imágenes (WhatsApp):** [`docs/manual-usuario/whatsapp-especificaciones-imagenes.txt`](./docs/manual-usuario/whatsapp-especificaciones-imagenes.txt)
- Sprints y tareas: **[`docs/roadmap.md`](./docs/roadmap.md)**

## Inicio rápido

```bash
cp .env.example .env.local
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
